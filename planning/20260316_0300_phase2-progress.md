## Session Summary (2026-03-16)

### Visualization Strategy Revision
Replaced the stability-score gradient with an event-driven representation:
- **Country fill:** binary — active conflict (deep crimson) vs peaceful (dark navy)
- **Country borders:** each nation's dominant flag color (hex lookup per ISO2)
- **Conflict markers:** ⚔ emoji at country centroid via Globe.gl `htmlElementsData` layer
- **Digest panel:** event cards (paragraph + image placeholder) instead of stability meter
- **Stability score:** retained in data model, shown deemphasized at panel footer

Rationale: avoids value judgements, represents facts on the ground, more defensible.

## What's Built (Phase 2 — this session)

### Perplexity Drop Zone + Ingestion Pipeline

| Path | Purpose |
|---|---|
| `backend/data/inbox/` | Perplexity drops `.json` files here |
| `backend/data/processed/` | Successfully ingested files archived here |
| `backend/data/failed/` | Failed files + `.error.json` reports quarantined here |
| `backend/data/normalized/` | Per-country normalised JSON (primary persistent store) |
| `backend/perplexity-spec/INSTRUCTIONS.md` | Full format spec for Perplexity |
| `backend/perplexity-spec/example-package.json` | Complete two-country example |
| `backend/src/lib/perplexity/schema.ts` | Dual schemas: RawPackage (permissive) + NormalizedPackage (strict Zod) |
| `backend/src/lib/perplexity/fuzzy.ts` | resolveCountryCode (ISO2/ISO3/name/Levenshtein), resolveEventType, resolveIntensity, resolveBoolean |
| `backend/src/lib/perplexity/validate.ts` | Two-phase validation: rescue + strict Zod; partial packages accepted |
| `backend/src/lib/perplexity/ingest.ts` | scanInbox(), disk-first writes, Redis cache layer |
| `backend/src/routes/ingest.ts` | POST /api/ingest/run, GET /api/ingest/status |
