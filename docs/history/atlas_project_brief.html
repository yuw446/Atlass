Project Brief · v0.1 · Mar 2026

ATLAS

A Living Globe of Global Tensions
Creative & Data Viz Web · Real-time Perplexity + Claude
01 Vision & Concept
"A traditional operating system takes instructions. ATLAS takes the chaos of global news and renders it as something you can feel — a living strategy game you can't pause."

ATLAS is a real-time geopolitical visualization that renders nation-state relationships as a living, interactive 3D globe — borrowing the visual language of Civilization to make abstract international dynamics legible at a glance. Every country on the globe is alive: its color, pulse, and border glow encode what's happening inside and between nations right now.

The globe operates on two simultaneous scales. At the macro level, arcs between nations encode trade flows, diplomatic relationships, sanctions, and military alliances — their thickness and color shift as real-world events unfold. At the micro level, each nation carries an internal stability index derived from protest activity, civil unrest, and social friction — nations under pressure flicker and fracture visually, reflecting the Civ mechanic of internal instability undermining external power projection.

Click any country to open a narrative digest panel — a Claude-generated editorial summary that reads like a foreign correspondent's briefing. Not a list of facts: a story about what this country is experiencing, why it matters, and how it connects to its neighbors.

02 Globe Visual System

Five simultaneous visual layers encode distinct data dimensions without cluttering the interface:

L1
Nation fill color
Stability hue — cool blue (stable) shifting through amber to deep red (volatile). Derived from protest index + governance score.
L2
Border glow
Alliance strength between neighboring nations. Bright = strong treaty/alliance. Dim = neutral. Pulsing red = active border dispute.
L3
Relationship arcs
Curved arcs between countries — color-coded by type (trade = teal, conflict = red, diplomacy = amber), thickness = relationship intensity.
L4
Internal pulse animation
Subtle shimmer within national borders when civil unrest is high. A country tearing apart from within while maintaining a diplomatic face outward.
L5
Click → Digest panel
Slides in from the right. Claude-generated 4–5 sentence narrative briefing + 3 top news source links. Refreshes on each click.

04 Perplexity + Claude Integration

The two services handle fundamentally different cognitive tasks — Perplexity Computer as the autonomous researcher running in the background, Claude as the narrative voice responding on demand.

Perplexity Computer
Runs every 4–6 hours as a scheduled agentic task
Scans global news sources across 50+ major bilateral relationships
Scores each relationship: alliance / neutral / tense / hostile
Detects active protest / unrest events per country and estimates intensity
Identifies the 3 most significant news events per country
Outputs structured JSON stored in Redis cache for globe consumption
Uses bonus credit period to run richer, more frequent research passes
Claude
Triggered on-demand when user clicks a country
Receives: country name, current scores, top 3 events, neighboring relationships
Generates 4–5 sentence narrative digest in a consistent editorial voice
Frames the story — not a list of facts but a coherent geopolitical narrative
Surfaces the why: how internal pressures connect to external behavior
Caches digest for 2 hours so repeat clicks are instant
Claude's increased usage limits enable richer, more detailed briefings
Example data flow — user clicks Brazil
Click → fetch Redis cache for BR → pass to Claude:
"Brazil: stability=62, unrest=high (Belém protests), top relationships: Argentina (tense), US (neutral), China (strong trade). Recent events: [3 GDELT entries]"
→ Claude outputs: "Brazil is turning inward. With the Amazon summit collapsing and Belém in its third week of protests over land rights, Lula's government is caught between its international climate commitments and domestic pressure from agribusiness interests — a tension that's quietly cooling its relationship with Buenos Aires while Beijing watches patiently from the sidelines."

06 Build Roadmap
Phase 1
The Globe
Spinning 3D globe with country borders, hover states, and color coding from hardcoded stability scores. Get the visual feel and interaction right before any real data. Globe.gl makes this surprisingly fast — the goal here is the aesthetic, not the data.
Est. ~1 week
Phase 2
Data Pipeline
Wire up GDELT for live event ingestion. Build the Perplexity Computer agent prompt that outputs structured relationship JSON every 4–6 hours. Set up Redis caching layer. Replace hardcoded scores with live data.
Est. ~1 week
Phase 3
Claude Digest Panel
Click handler → country context → Claude API → animated slide-in panel. Define the editorial voice system prompt. Add news source links. Cache responses. This is the layer that turns it from a visualization into a story.
Est. ~3–4 days
Phase 4
Arc Relationships + Unrest Pulse
Animated arcs between countries color-coded by relationship type. Internal pulse animation for unrest. Layer toggle UI so users can isolate trade, conflict, or diplomatic arcs. Filter panel for region / arc type.
Est. ~1 week
Phase 5
Polish + Deploy
Performance optimization (arc culling for off-screen countries), mobile responsiveness, loading states, error handling, Vercel deployment. Optional: time-scrubber to replay the globe's state over the past 30 days.
Est. ~ongoing
07 Visual Design Direction
Globe aesthetic
Dark navy void. Countries as matte surfaces. Arcs glow like light on glass. Feels like a war room, not a data dashboard.
Color system
Stability: cold blue → amber → deep red. Arcs: teal (trade), orange (diplomacy), red (conflict), gray (neutral).
Typography
Country labels in tight caps. Digest panel in a refined serif — the contrast between the cold map and the warm editorial voice matters.

The Civ reference is about legibility and weight — not literal gamification. The globe should feel like something consequential is being revealed. Not playful; geopolitically serious with a cinematic edge. Think less Bloomberg Terminal, more Dr. Strangelove war room crossed with a Verso Books cover.

08 Open Questions to Resolve
QuestionStakes
Globe.gl vs raw Three.js?Globe.gl is faster to prototype; Three.js gives more visual control. Start with Globe.gl, migrate if needed.
How many bilateral relationships to track?All 195² pairs is computationally excessive. Prioritize G20 + active conflict zones (~60–80 pairs) for MVP.
Perplexity Computer refresh cadence?Bonus credits are finite. Balance freshness vs credit burn — 4–6h refresh for major pairs, 24h for quiet ones.
GDELT data quality?GDELT is noisy — needs filtering to avoid false positives. Perplexity's layer provides the sanity check.
Time-scrubber feature?Compelling but complex — requires historical data storage. Defer to Phase 5 or beyond.
